# 中国商品期货全市场每日扫描

每个交易日收盘后，对国内商品期货重点品种做一次深度扫描，覆盖基本面、分析逻辑和技术面。

## 怎么看

用浏览器打开仓库根目录的 [index.html](./index.html)，即可阅读最新一期。历史期次在 [`scans/`](./scans/) 目录，按日期命名。

页面支持浅色 / 深色切换，也可在手机上打开。
